# Handbook development samples

Copy this folder into a disposable world's `datapacks` directory and enable it with
`/datapack enable "file/handbook-samples"`. Run `/reload` after edits. This pack requires Chisel on Minecraft 26.1.2.

It adds the Testing category, ten pagination guides, and the oversized handbook test lab. The test lab intentionally
references a missing block to exercise fallback display and warnings. Literal text makes this pack usable without a
companion resource pack.

These resources are outside the mod's source sets and do not ship in its jar.
See [the authoring guide and manual checklist](../../docs/handbook.md).
